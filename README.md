# 안녕하세요, 김성현(Ditto)입니다 👋

**고객의 니즈를 이해하고, 전략적 사고와 개발을 연결하는 프로덕트 엔지니어를 지향합니다.**

프론트엔드 개발자로 시작했습니다. 고객에게 필요한 해결책을 더 빠르게 전달하기 위해 문제의 맥락과 우선순위를 고민하고, AI를 활용하며 개발 범위를 넓혀 왔습니다. 화면 구현부터 서버 API 개발까지 참여하며, 고객이 제품을 사용하는 전체 흐름을 이해하고 개선하는 데 관심을 두고 있습니다.

## 운영 중인 서비스를 개선해 왔습니다

- **점진적 리팩토링** — 실제 운영 환경에서 기존 동작과 변경의 영향을 살피며, 서비스의 구조를 단계적으로 개선해 왔습니다.
- **안정적인 배포** — 운영 중인 서비스에 변경 사항을 안정적으로 배포하며, 구현한 개선이 실제 사용자에게 전달되는 과정까지 경험했습니다.
- **프론트엔드에서 서버 API까지** — 고객의 니즈를 해결하는 데 필요한 영역으로 역할을 넓혀, 화면과 서버를 연결하는 개발에 참여해 왔습니다.

## 운영과 개발을 함께 생각합니다

**고객의 문제에서 출발합니다.** 고객이 무엇을 필요로 하는지 이해하고, 어떤 문제를 먼저 해결해야 할지 전략적으로 판단합니다.

**AI로 실행 속도를 높입니다.** 문제를 탐색하고 해결책을 구현하는 과정에 AI를 활용하며, 고객에게 필요한 변화를 빠르게 전달하고자 합니다.

**운영의 맥락을 함께 봅니다.** 구현 속도와 유지보수성, 운영 안정성을 함께 고려하며 지속적으로 개선할 수 있는 제품을 지향합니다.
